\chapter{Introduction}
\label{chap:introduction}

Reliable radio coverage prediction is a central requirement for future 6G
systems. A channel knowledge map (CKM) is a site specific repository of channel
information that can support environment aware planning and reduce online
channel acquisition overhead \cite{zengx2021ckm,ckmtutorial2024}. Classical ray
tracing can generate detailed CKMs, but it is too expensive to repeat for every
candidate city, transmitter height and deployment assumption.

Unmanned aerial vehicles (UAVs) make this prediction problem more useful and
more difficult. In Third Generation Partnership Project (3GPP) terminology, a
UAV mounted radio access node is called a UxNB \cite{threegpp22125}, so the
transmitter height is no longer a fixed rooftop constant. It becomes a
continuous input that changes visibility, interference patterns and multipath
spread. The dataset used here defines the transmitter as a UAV operating at
\SI{7.125}{GHz}; within the same simulation setting, the model can also be
read as a surrogate for other elevated radio access nodes in the sampled height
range.

Existing radio map models and open challenges show that image based prediction
can be accurate under controlled benchmark settings, but they often use fixed transmitter
height, random splits, smaller maps, or only one attenuation target. The gap
addressed here is stricter: dense \(513\times513\) prediction of channel
attenuation, delay spread (DS) and angular spread (AS) for whole cities that were not
seen during training, with continuous UAV height and valid ground receiver
metrics.

This thesis proposes and evaluates \textsc{HARP-Net CKM}, the Height-Aware
Residual Prior Network for CKM prediction. In the terminology of this thesis,
the CKM is the dense channel map to be predicted, and \textsc{HARP-Net CKM} is
the proposed system that predicts it. At a high level, the pipeline first builds
physically meaningful support maps and priors calibrated only on training
cities, and then the neural model corrects the remaining local errors. For the
CKM experiments, the line of sight and non line of sight (LoS/NLoS) visibility
mask is read from the dataset; for topology only deployment it can be generated
geometrically from the building map and transmitter height. The neural network
therefore focuses on residual radio map structure instead of being asked to
rediscover all propagation geometry from scratch.

\textbf{Terminology.} The CKM HDF5 file and the training code name the dB
attenuation target \texttt{path\_loss}, and the implementation keeps the
abbreviation PL for compatibility with those files. In the prose of this
thesis, that predicted dense dB map is referred to as \emph{channel
attenuation}. The term \emph{path loss} is kept when discussing standard
propagation formulas, cited path loss models, or code and dataset names that
explicitly use it.

\section{Motivation}
\label{sec:intro_motivation}

The practical motivation is the cost of asking detailed propagation tools the
same question many times. A planner may want to compare several UAV heights,
candidate deployment areas, neighbourhood types, or operating assumptions
before selecting where a temporary aerial node should fly. Ray tracing is
valuable for producing accurate reference maps, but it is not convenient as an
interactive design tool when every new city or height requires another full
simulation. A learned CKM surrogate is useful if it can keep the physically
important map structure while producing new dense predictions quickly enough
for repeated what if analysis.

The scientific motivation is that this usefulness only matters if the model
generalises beyond the places used to fit it. Randomly splitting pixels or
tiles can make a radio map predictor look strong while still allowing the
training and test sets to share the same streets, building styles and blockage
patterns. That is not the deployment situation considered here. The model is
asked to predict complete unseen cities, and the UAV transmitter height is a
continuous variable rather than a small set of fixed cases. The task therefore
tests whether the method has learned transferable relations between geometry,
visibility, height and channel behaviour.

A second motivation is that channel attenuation alone is an incomplete
description of a CKM. Attenuation gives the received power scale, but delay
spread and angular spread describe how dispersed the received energy is in time
and direction. These quantities affect equalisation, beam selection and link
robustness, yet the reviewed literature rarely reports them as dense per pixel
maps over full unseen cities. Treating DS and AS as first class outputs makes
the thesis more demanding than a single path loss map benchmark and also
forces the evaluation to be explicit about units, masks and comparison
rules.

Finally, the motivation for the hybrid design came from the behaviour of the
dataset itself. The channel attenuation prior is already very strong under the
final CKM evaluation protocol, especially because the visible regions contain regular
distance and two-ray structure. At the same time, direct neural regression can
hide failures in blocked regions or in the long tails of the spread targets.
For this reason, the thesis does not frame deep learning as a replacement for
all propagation knowledge. It uses calibrated priors to capture the stable
part of the problem and asks the neural model to learn the residual structure
that remains.

\section{State of the art gap and thesis position}
\label{sec:intro_sota_gap}

The state of the art reviewed in Chapter~\ref{chap:soa} is strong, but it does
not solve this exact CKM problem. Radio map neural networks such as PMNet,
RadioUNet and newer transformer variants show that dense path loss maps can be
predicted accurately under their own benchmark setups. However, those
setups usually differ from this thesis in at least one important dimension:
fixed or rooftop transmitter height, random or same distribution splits,
different map resolution, different building pixel treatment, or only one
attenuation target. UAV air to ground and 3GPP style models explain height,
LoS/NLoS and spread statistics, but they do not by themselves generate dense
channel attenuation, delay spread and angular spread maps for unseen cities.

This thesis aims to go beyond that gap in three linked ways. First, RQ1 asks for
one dense surrogate that predicts all three CKM targets on strict city holdout
splits, rather than reporting only a shuffled or same city attenuation score.
Second, RQ2 asks how far transparent priors can go before a neural residual is
needed, instead of treating the network as a black box replacement for all
propagation structure. Third, RQ3 asks whether continuous UAV height can be
handled by one height conditioned model rather than by separate fixed height
experiments. The contributions listed below follow this same mapping: final
pipeline and evaluation protocol for RQ1, calibrated priors and residual model
for RQ2, and height conditioned analysis for RQ3.

\section{Work goals}

The initial technical targets were defined in physical units and were kept as
the main success criteria throughout the project. The proposal also included a
runtime objective, because a surrogate is only useful if it is clearly faster
than generating the same maps through ray tracing:

\begin{itemize}
  \item channel attenuation RMSE below \SI{5}{dB};
  \item delay spread RMSE below \SI{50}{ns};
  \item angular spread RMSE below \SI{20}{\degree};
  \item separate reporting for global, LoS, and NLoS regions;
  \item a 10 to 100\(\times\) reduction in channel map generation time compared
        with ray tracing.
\end{itemize}

These numerical targets were set in the project proposal and kept unchanged
throughout the thesis. They are meant to match the order of magnitude at which a
ray tracing surrogate starts being useful for planning and coverage decisions. A
few dB of channel attenuation RMSE is already a strong target for a
city holdout, continuous height CKM dataset, because it is compatible with
practical link budget margins while still preserving spatial structure. Delay
spread and angular spread are harder to benchmark externally: the reviewed
literature rarely reports dense per pixel DS/AS maps over full unseen cities, so
their targets are used mainly as project level usefulness thresholds and are
interpreted against the same protocol frozen priors. The results chapter checks
the runtime target explicitly by comparing the measured final generator time
with the measured MATLAB ray-tracing time on the same Barcelona geometry and
hardware.

The most important methodological objective was not only to obtain a low
average RMSE, but to do so under a strict city holdout split. City holdout
means that entire cities, not individual pixels or tiles, are reserved for
validation and testing. A test city therefore contains no samples that were
seen during training. This is harder and more deployment-relevant than random
pixel or random tile splitting, because the model must work on urban layouts it
has never seen.

\section{Research questions, answers and contributions}

The thesis is organised around three research questions, which also define
the three main scientific claims of the final pipeline:

\begin{itemize}
  \item \textbf{RQ1.} Can a single deep learning surrogate predict per pixel
        channel attenuation, delay spread, and angular spread on \(513\times513\)
        channel knowledge maps, under strict city holdout evaluation, with
        errors compatible with the thesis targets?
  \item \textbf{RQ2.} Which part of the prediction should be left to a
        calibrated analytic prior and which part should be left to the neural
        network, so that the hybrid model is both accurate and interpretable?
  \item \textbf{RQ3.} How does the continuous UAV transmitter height
        (\SIrange{12}{478}{m}) affect the prediction error, and is the same
        architecture able to cover the full height range without per height
        retraining?
\end{itemize}

In simple terms, the final answer to the three questions is positive within the
fixed CKM simulation setting used in this thesis. \textsc{HARP-Net CKM}
predicts channel attenuation, delay spread, and angular spread on cities that
were not used for training. The reason it works is not that the neural network
learns all propagation physics from zero. Stable effects such as distance,
visibility, transmitter height, and city type are first captured by calibrated
priors; the neural network then corrects the remaining local errors. The hardest
cases are still low altitude and strongly blocked NLoS regions, so the results
are always reported by regime instead of only as one global RMSE. The results
and conclusions give the full technical answer.

The main contributions corresponding to these questions are:

\begin{itemize}
  \item A reproducible CKM prediction pipeline for ground users served by a
        centred UAV transmitter, with the same height variable also usable for
        other elevated radio access nodes under the same simulation setting.
        The evaluation uses \(513\times513\) maps,
        city holdout train/validation/test splits, valid ground receiver pixels
        only, and continuous UAV transmitter height conditioning.
  \item A channel attenuation prior calibrated only on training cities, combining
        LoS propagation based on the coherent two-ray model with NLoS calibration
        over environment features. The prior provides a transparent baseline
        whose exact held out city accuracy is reported in the results chapter.
  \item Delay spread and angular spread priors, also calibrated only on training
        cities, based on log domain ridge regression over geometry, visibility,
        transmitter height, and environment features.
  \item \textsc{HARP-Net CKM}, a shared neural model that receives the frozen
        PL, DS, and AS priors and learns bounded residual corrections for the
        three maps jointly.
  \item A distribution shape analysis showing that earlier point regression
        networks tended to average away difficult NLoS and spread tail cases.
        This motivates using mixture style residual predictions instead of a
        single direct regression value everywhere.
\end{itemize}

\section{Thesis outline}

Chapter~2 reviews the state of the art and the technical background needed for
the thesis: classical propagation models, radio map deep learning, hybrid
physics/neural methods, distribution aware prediction, and fair comparison
criteria. Chapter~3 describes the final methodology: the CKM dataset, the
ground receiver evaluation rules, the city holdout split, the calibrated
priors, and the \textsc{HARP-Net CKM} residual model. The method chapter is
intentionally final pipeline first; the chronological attempt trace is kept in
Appendix~A. Chapter~4 reports the final quantitative results, the comparison
with the frozen priors and the closest published benchmarks, qualitative
examples, runtime, and limitations. Chapter~5 discusses sustainability,
economic impact, social impact, and ethical scope. Chapter~6 answers the
research questions and presents future work. The appendices preserve the
development trace, representative panels, generator documentation, and the
declaration on generative AI use.

The main deviation from the initial plan was the discovery that a standard
image to image convolutional network could look plausible in LoS dominated
regions while still failing badly in blocked regions. This forced stricter
ground receiver masking, regime diagnostics, topology and height audits,
physical priors, and finally the prior anchored residual design used by the
final system. The result is a project whose final method is more hybrid and
more interpretable than the initial proposal anticipated.

\section{Requirements and specifications}

The project uses the CKM HDF5 dataset
\texttt{CKM\_Dataset\_270326.h5}. The CKM dataset contains 66 real city
scenarios and 16180 samples. Each sample is a $513\times513$ pixel raster with
the following fields:

\begin{table}[ht]
\centering
\caption{Main CKM dataset fields used in the thesis.}
\label{tab:dataset_fields_intro}
\begin{tabularx}{\textwidth}{lllX}
\toprule
Field & Shape & Type & Role \\
\midrule
\texttt{topology\_map} & $513^2$ & float32 & Building height in metres. Pixels with buildings are not valid receiver locations. \\
\texttt{los\_mask} & $513^2$ & uint8 & Binary LoS/NLoS visibility mask. \\
\texttt{path\_loss} & $513^2$ & uint8 & Ray-traced channel attenuation in dB, named \texttt{path\_loss} in the dataset and quantized at approximately \SI{1}{dB}. \\
\texttt{delay\_spread} & $513^2$ & uint16 & Delay spread target, stored as integers and evaluated in ns after decoding. \\
\texttt{angular\_spread} & $513^2$ & uint8 & Angular spread target, stored as integers and evaluated in degrees after decoding. \\
\texttt{uav\_height} & scalar & float32 & UAV transmitter height in the dataset, used as transmitter height for conditioning and physical priors. \\
\bottomrule
\end{tabularx}
\end{table}

The physical receiver scenario is a ground user served by the UAV transmitter. Therefore,
losses and metrics are computed only on valid ground receiver pixels. Building
pixels remain in the topology input because they affect propagation, but they
are excluded from error accumulation because no receiver is placed inside a
building pixel. The fixed receiver height used in the analytic priors is
\SI{1.5}{m}. The transmitter is the UAV antenna, whose height varies
continuously across the dataset.
