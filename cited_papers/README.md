# Cited Paper Downloads

Source bibliography: `FINAL_THESIS/reduced/TFG/TFG.bib`.

This folder contains the cited papers that could be downloaded from official or open sources. The download pass did not use unofficial paywall bypasses.

- `download_manifest.csv` lists every BibTeX entry and its status.
- `download_manifest.json` is the same manifest in JSON form.
- `open_pdf_not_found.txt` lists cited papers where no open script-accessible PDF was found.
- `summary.json` contains the current counts.
- `cost231_final_report_parts/` contains the official COST 231 final report PDF parts, because that report is distributed as zipped chapter PDFs rather than one PDF.

Current summary:

- 41 paper PDFs downloaded or already present according to the manifest.
- 1 report downloaded as official PDF parts.
- 10 non-paper/software/book/web entries skipped.
- 8 cited papers still require library access or manual browser access.
